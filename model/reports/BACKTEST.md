# PitWall backtest

Seasons 2020-2026, each predicted by a model trained only on earlier seasons. Generated by `uv run pitwall model backtest`.

Model kinds: `pl` is a Plackett-Luce regression on the finishing order; `blend` averages it with a LightGBM ranker. The kind used in each mode was chosen on this backtest, which flatters the numbers slightly; the live public scorecard from 2027 is the clean test.

| 2023 | R15/22 | max_verstappen | 100% | red_bull | 100% |
| 2024 | R16/24 | max_verstappen | 98% | mclaren | 41% |
| 2025 | R16/24 | norris | 15% | mclaren | 100% |
