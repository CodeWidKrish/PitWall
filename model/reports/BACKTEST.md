# PitWall backtest

Seasons 2020-2026, each predicted by a model trained only on earlier seasons. Generated by `uv run pitwall model backtest`.

Model kinds: `pl` is a Plackett-Luce regression on the finishing order, `lgbm` a LightGBM ranker, `blend` an average of the two. For every test season the kind is chosen by walk-forward validation on the two previous seasons only, so no choice is made with knowledge of the season being tested.

## Championship forecasts

Each finished season simulated from five points (pre-season, 25%, 50%, 67% and 80% distance) with a model trained only on earlier seasons. The size of the season-long form swing is tuned on these forecasts: pre-season and in-season separately.

| Swing scale | Pre-season log loss | In-season log loss |
|---|---|---|
| 0.0x | 1.0221 | 0.5773 |
| 0.5x | 1.1121 | 0.5515 |
| 1.0x | 1.1934 | 0.5181 |
| 1.5x | 1.2325 | 0.481 |
| 2.0x | 1.3531 | 0.4972 |
| 3.0x | 1.5687 | 0.5522 |

Lowest log loss: 0.0x before the season, 1.5x during it (1x = team 0.6, driver 0.3 in log-odds).

In use: 1.5x before the season, 1.5x during it. The pre-season value is overruled: it rests on six forecasts, and with no swing the model gave an eventual champion 0% (McLaren, 2024). Winter changes are at least as uncertain as in-season ones, so pre-season uses the in-season value.
